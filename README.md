# PyDocAlgo - Find The Right Python Functions!

## Description
An algorithmic AI bot that searches a CSV file for a Python function that matches the given query. The bot takes in a query, processes it using Python's NLTK, then searches a CSV file containing functions from a variety of Python modules, including `numpy`, `scipy` and `pandas`.
