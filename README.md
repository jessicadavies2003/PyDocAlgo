# PyDocAlgo - Find The Right Python Functions!

## Description
An algorithmic chatbot that searches a CSV file for a Python function that matches the given query. The bot takes in a query, processes it using Python's NLTK, then searches a CSV file containing functions from a variety of Python modules, including `numpy`, `scipy` and `pandas`.

## Getting Started
1. Download this repository as a .ZIP file.
2. Extract its contents.
3. Open CMD
4. Type `cd` then the filepath to this directory.
5. Run `py main.py` file.
